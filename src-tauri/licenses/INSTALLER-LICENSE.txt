SYSTEM INFORMATION

Product: Racore Browser
Version: 0.1.0
Supported installer architecture: Windows x64
Application shell: Tauri + Microsoft WebView2
Local control plane: racored (Go)
Local AI model: MadeAgents/Hammer2.0-0.5b, Q8_0
Local inference engine: llama.cpp, CPU-first
Local storage and publishing: IPFS Kubo
Network: Racore Mesh and signed Racore domains
AI privacy: no cloud inference provider or API key is required
